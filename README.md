# Auto-Intoxication Feedback Loop

This research shows how AI systems can poison themselves.

## Key Results:
- Starting with 13% fake content
- Reaches 50% contamination in 17 iterations
- Final contamination: 72.6% after 50 iterations
- Decay constant: 0.0480
